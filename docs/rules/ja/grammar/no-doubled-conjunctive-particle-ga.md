# 逆接の「が」の使いすぎ

**ルールID:** `no-doubled-conjunctive-particle-ga` · **重要度:** error · **言語:** 日本語

一つの文の中で逆接の「が」（「〜だが、〜だが」のように話をひっくり返す使い方）が2回以上出てくると、結局何が言いたいのかがわかりにくくなります。このルールはそうした逆接の「が」の連続を検出します。「雨が降る」「彼が来る」のような主語を表す「が」は対象外で、逆接の意味で使われている「が」だけを数えます。「が」の直前の言い回しから逆接かどうかを判断しているため、ごく特殊な言い回しでは逆接の「が」を見逃すことがありますが、主語の「が」を誤って逆接と指摘してしまう方向にはほとんど倒れません。

## 例

**❌ 検出される例:**
> 今日は早朝から出発したが、定刻には間に合わなかったが、無事会場に到着した。

**理由:** 「〜が」で文をつなぐ逆接の使い方が2回続いており、話がどちらの方向に転じているのか読み手が追いにくくなっています。

**✅ より自然な例（参考例）:**
> 今日は早朝から出発したが、定刻には間に合わなかった。それでも無事会場に到着した。

もう一例です。

**❌ 検出される例:**
> 検討するが、難しいが、やる。

**理由:** 短い文の中で逆接の「が」が畳みかけるように使われ、文の流れが不自然になっています。

**✅ より自然な例（参考例）:**
> 検討したが難しかった。それでもやる。
