# 二重否定表現

**ルールID:** `no-double-negative-ja` · **重要度:** error · **言語:** 日本語

「〜なくもない」「〜ないわけではない」のように否定を二重に重ねる言い方は、遠回しで意味がつかみにくく、結局賛成なのか反対なのかはっきりしません。このルールは「〜なくもない」「〜ないでもない」「〜ないことはない」「〜ないわけではない」「〜ないものではない」「〜とはいいきれない」「〜とはかぎらない」など、よくある二重否定のパターンを幅広く検出します。「言い切れない」と「いいきれない」のように、漢字表記でもひらがな表記でも同じように検出されます。

## 例

**❌ 検出される例:**
> だが、それが事件の発端だったといえなくもない。

**理由:** 「〜といえなくもない」は否定を二重に重ねた遠回しな言い方で、はっきり言い切った方が伝わりやすくなります。

**✅ より自然な例（参考例）:**
> だが、それが事件の発端だったと言える。

もう一例です。

**❌ 検出される例:**
> できないことはない。

**理由:** 「〜ないことはない」も二重否定で、実際にできるのかどうかが曖昧になっています。

**✅ より自然な例（参考例）:**
> できる。
