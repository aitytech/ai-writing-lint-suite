# 「である」調と「ですます」調の混在

**ルールID:** `no-mix-dearu-desumasu` · **重要度:** error · **言語:** 日本語

一つの文書の中で「である」調（〜だ、〜である）と「ですます」調（〜です、〜ます）が混ざっていると、文章全体の落ち着きがなくなり、読み手に統一感のなさを感じさせます。このルールは見出し・本文・箇条書きをそれぞれ集計し、その中で多数派の文体と異なる箇所だけを指摘します。「これは便利だが、少し高い。」のように文の途中でつなぐ「だが」や、「不明な点」のように名詞を修飾する「な」は、文末の言い切りではないため対象外です。ごくまれに、活用形によって判定がずれるケースが残っていますが、対象外にすべき箇所を誤って拾ってしまう方向にはほとんど倒れません。

## 例

**❌ 検出される例:**
> これは重要です。以前は不明な点も多かったのですが、今ではすべて明らかであった。それでも重要です。とても重要です。

**理由:** 本文は「ですます」調で統一されていますが、「明らかであった」の部分だけ「である」調になっており、文体が浮いてしまっています。

**✅ より自然な例（参考例）:**
> これは重要です。以前は不明な点も多かったのですが、今ではすべて明らかです。それでも重要です。とても重要です。

もう一例です。

**❌ 検出される例:**
> 彼は学生だ。価格も手頃だ。品質は良いです。

**理由:** 本文の大半は「である」調（だ）で書かれているのに、最後の一文だけ「ですます」調に変わっており、統一感がありません。

**✅ より自然な例（参考例）:**
> 彼は学生だ。価格も手頃だ。品質は良い。
