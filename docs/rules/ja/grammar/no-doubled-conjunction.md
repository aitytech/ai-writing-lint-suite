# 同じ接続詞の連続使用

**ルールID:** `no-doubled-conjunction` · **重要度:** error · **言語:** 日本語

隣り合う文の頭で「しかし」「そして」のような同じ接続詞が続けて使われていると、文章が単調になり、論理のつながりも見えにくくなります。このルールは隣接する文の先頭の接続詞を比較し、同じ接続詞が連続していないかを検出します。

## 例

**❌ 検出される例:**
> しかし、これは問題だ。しかし、解決できる。

**理由:** 「しかし」が2文続けて使われており、逆接が重なることで話の流れがぎこちなくなっています。

**✅ より自然な例:**
> しかし、これは問題だ。だから、解決する。

後半の接続詞を「だから」に変えるだけで、話の展開に変化が生まれます。

もう一例です。

**❌ 検出される例:**
> そして、Aである。そして、Bである。

**理由:** 「そして」が単純に繰り返されており、二つの文の関係が並列以上の意味を持たなくなっています。

**✅ より自然な例（参考例）:**
> そして、Aである。また、Bである。
