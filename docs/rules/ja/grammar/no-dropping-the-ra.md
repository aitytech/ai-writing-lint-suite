# ら抜き言葉

**ルールID:** `no-dropping-the-ra` · **重要度:** error · **言語:** 日本語

「食べれる」「見れる」のように、本来「られる」となるべきところから「ら」が抜けた、いわゆる「ら抜き言葉」を検出するルールです。話し言葉では広く使われていますが、書き言葉、特にきちんとした文章では避けた方がよいとされています。なお、辞書に載っていない一部の動詞のら抜き形までは見逃すことがありますが、正しい「られる」の言い方を誤って指摘してしまうことはありません。

## 例

**❌ 検出される例:**
> ケーキが食べれる。

**理由:** 「食べれる」は「食べられる」の「ら」が抜けた形です。書き言葉では「られる」を使うのが基本です。

**✅ より自然な例:**
> ケーキが食べられる。

もう一例です。

**❌ 検出される例:**
> この番組は見れますか。

**理由:** 「見れます」も同様に「見られます」の「ら」が抜けています。

**✅ より自然な例:**
> この番組は見られますか。
