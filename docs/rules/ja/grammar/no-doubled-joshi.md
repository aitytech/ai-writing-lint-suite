# 同じ助詞の連続使用

**ルールID:** `no-doubled-joshi` · **重要度:** error（助詞の間隔が1トークン以下で連続すると検出）· **言語:** 日本語

「材料不足で代替素材で製品を作った。」のように、同じ助詞（で・は・が など）が近い間隔で繰り返し出てくると、文の構造が追いにくくなります。このルールはそうした助詞の連続を見つけて教えてくれます。「〜たり〜たり」のような並立表現や「〜かどうか」といった決まった言い回しは例外として扱われるため、正しい日本語が誤って指摘されることはありません。

## 例

**❌ 検出される例:**
> 材料不足で代替素材で製品を作った。

**理由:** 「で」という助詞が短い間隔で2回使われており、どこからどこまでが一つのまとまりなのかが読み取りにくくなっています。

**✅ より自然な例（参考例）:**
> 材料不足のため、代替素材で製品を作った。

もう一例です。

**❌ 検出される例:**
> 私は彼は好きです。

**理由:** 「は」が2回連続して使われており、主題がどちらなのか曖昧になっています。

**✅ より自然な例（参考例）:**
> 私は彼が好きです。
