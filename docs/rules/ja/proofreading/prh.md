# 表記ゆれをそろえる（用語辞書チェック）

**ルールID:** `prh` · **重要度:** info · **言語:** 日本語

同じ意味の言葉が文書の中でバラバラに書かれていないかをチェックするルールです。「サーバー」と「サーバ」、「インターフェース」と「インタフェース」のように、どちらも間違いではないのに表記だけが揺れていると、読み手は無意識に引っかかりを感じてしまいます。

## 根拠

このルールが使う辞書は、技術書出版社「WEB+DB PRESS」が公開している用字用語統一ルールを azu 氏がゆるやかに整理し直したもの（[azu/prh.yml](https://github.com/azu/prh.yml) の `ja/web+db.yml`、MITライセンス）です。データファイルの見出しコメントには「WEB+DB PRESS用語統一ファイルをよりゆるやかにした辞書」「削除: 他のルールと衝突しやすいもの、組版向け記号、全角記号に関するもの」と明記されています。本プリセットはこの辞書をそのまま取り込んで使っています。

## 例

**❌ 検出される例:**
> この製品のインターフェースは優れている。

**理由:** 辞書では「インタフェース」への統一が推奨されており、「インターフェース」は表記ゆれとして報告されます（メッセージ: インターフェース => インタフェース）。

**✅ より自然な例:**
> インタフェースを実装する。

もう1パターン、長音符の有無でも同じことが起きます。

**❌ 検出される例:**
> サーバーの設定をする。

**理由:** 辞書は「サーバ」への統一を推奨しているため、「サーバー」が報告されます（メッセージ: サーバー => サーバ）。

**✅ より自然な例:**
> サーバの設定を確認する。
