# 漢字の連続をチェックする

**ルールID:** `max-kanji-continuous-len` · **重要度:** info · **言語:** 日本語

漢字だけの文字列が長く連続していないかを検出するルールです。漢字が固まって続くと、単語の切れ目がどこにあるのか読み手がすぐに判断できず、読みにくさにつながります。

## 根拠

日本心理学会第79回大会の発表「漢字含有率と漢字連続長が文章の印象に与える影響」を根拠に、漢字の連続が4〜5文字あたりに読みやすさの壁があるとされ、そこに余裕を持たせて6文字以上をデフォルトの上限としています。

## 例

**❌ 検出される例:**
> 国際連合安全保障理事会決議案を採択した。

**理由:** 「国際連合安全保障理事会決議案」の部分で漢字が6文字以上連続しており、既定の上限（5文字）を超えています。

**✅ より自然な例:**
> 国際連合の決議を採択した。
