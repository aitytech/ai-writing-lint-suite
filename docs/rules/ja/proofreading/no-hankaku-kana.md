# 半角カタカナをチェックする

**ルールID:** `no-hankaku-kana` · **重要度:** error · **言語:** 日本語

「ﾊﾝｶｸ」のような半角カタカナを検出するルールです。半角カタカナは古いシステムの文字コードの名残であることがほとんどで、現代の日本語の文章で意図的に使われることはまずありません。

## 根拠

JTF（日本翻訳連盟）「JTF日本語標準スタイルガイド」2.1.5 カタカナの項目を参考文献として挙げており、カタカナは全角で表記するのが標準的な扱いとされています。

## 例

**❌ 検出される例:**
> ﾊﾝｶｸのカタカナ。

**理由:** 半角カタカナ「ﾊﾝｶｸ」が使われています（メッセージ: 半角カタカナ: "ﾊﾝｶｸ"）。

**✅ より自然な例:**
> ハンカクのカタカナ。
