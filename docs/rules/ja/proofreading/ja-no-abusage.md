# よくある言葉の誤用をチェックする

**ルールID:** `ja-no-abusage` · **重要度:** error · **言語:** 日本語

「適応」と「適用」の混同や、「こんにちわ」のような定着した誤変換、「見ずらい」のような送り仮名の誤りなど、日本語でよく起きる言葉の取り違えを検出するルールです。文法的には成立してしまうため見落としやすいものの、読み手には違和感として伝わってしまう種類の間違いです。

## 例

**❌ 検出される例:**
> 法律を適応する。

**理由:** 「適応」は環境などに合わせるという意味で、法律や規則を当てはめる場合は「適用」が正しい表記です。

**✅ より自然な例:**
> 法律を適用する。

送り仮名の誤りも対象になります。

**❌ 検出される例:**
> この画面は見ずらい。

**理由:** 動詞の連用形に「辛い（つらい）」が続く場合は「ずらい」ではなく「づらい」が適切な表記です。

**✅ より自然な例:**
> この画面は見づらい。

変換ミスがそのまま定着してしまった言い回しも拾います。

**❌ 検出される例:**
> こんにちわ、世界。

**理由:** 「こんにちわ」は「こんにちは」の誤変換が定着したもので、正しくは助詞の「は」を使います。

**✅ より自然な例:**
> こんにちは、世界。
