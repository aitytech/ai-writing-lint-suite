# 不自然に混じったアルファベットを見つける

**ルールID:** `ja-unnatural-alphabet` · **重要度:** info · **言語:** 日本語

日本語の文中に、1文字だけのアルファベットが唐突に現れていないかを検出するルールです。IME（日本語入力システム）の変換ミスで、かなの代わりにローマ字がそのまま残ってしまうケースを見つけるためのものです。

## 根拠

CiNii掲載の論文「日本語文章校正ツール"Chanterelle" : 入力ミス及び表記揺らぎについて」を根拠に、母音（aiueo）と「n」は日本語の「ん」に変換されやすく誤入力として現れにくいため、デフォルトの除外対象になっています。

## 例

**❌ 検出される例:**
> これはＡＢＣです。

**理由:** 全角アルファベットの「Ａ」が不自然な位置に出現しています。英単語として書く場合は半角、日本語の中に単独の文字が混ざる場合は変換ミスを疑う、という判断に基づいています。

**✅ より自然な例:**
> これはABCです。
