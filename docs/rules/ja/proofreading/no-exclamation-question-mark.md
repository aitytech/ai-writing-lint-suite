# 感嘆符・疑問符の使用をチェックする

**ルールID:** `no-exclamation-question-mark` · **重要度:** info · **言語:** 日本語

文中の「！」「？」（全角・半角問わず）を検出するルールです。フォーマルな技術文書やレポートでは使わないのが一般的な一方、会話文やマーケティング文では自然に使われるため、重要度は「info」にとどめてあります。

## 例

**❌ 検出される例:**
> これは本当にすごい！

**理由:** 感嘆符「！」の使用が検出されています。フォーマルな文章では、感嘆符を使わずに言い切る書き方が一般的です。

**✅ より自然な例:**
> これは本当にすごい。
