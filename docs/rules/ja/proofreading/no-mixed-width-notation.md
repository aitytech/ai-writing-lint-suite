# 数字とローマ字の全角・半角をそろえる

**ルールID:** `no-mixed-width-notation` · **重要度:** info · **言語:** 日本語

同じ文書の中で、数字やアルファベットの全角・半角表記が入り混じっていないかを検出するルールです。全角と半角のどちらが正しいというルールではなく、1つの文書の中では表記を統一したほうが読みやすいという考え方に基づいています。

## 根拠

文化審議会国語分科会「公用文作成の考え方（建議）」（令和4年1月7日）Ⅰ表記の原則４エは、数字について「全角･半角は、文書内で使い分けを統一する」と述べています。同じくⅠ表記の原則６エは、ローマ字についても「全角・半角を適切に使い分ける」としています。JTF（日本翻訳連盟）「JTF日本語標準スタイルガイド」も2.1.8・2.1.9で「特別な理由がない限り半角での表記を原則とします」としつつ、5.4では特許・知財分野は全角が基本になると併記しており、分野によって慣行が異なることを踏まえた上での「文書内での統一」がどちらの資料にも共通する考え方です。

## 例

**❌ 検出される例:**
> 価格は500円、割引後は450円、特別価格は３９８円である。

**理由:** 半角数字（500円・450円）が多数を占める中に、全角数字の「３９８」が1件だけ紛れ込んでいます。全角自体が誤りなのではなく、同じ文書内で統一されていないことが問題です。

**✅ より自然な例（参考例）:**
> 価格は500円、割引後は450円、特別価格は398円である。

ローマ字でも同じことが起こります。

**❌ 検出される例:**
> WiFiとBluetoothを使う。ダウンロードはＦＴＰで行う。

**理由:** 半角のローマ字（WiFi、Bluetooth）が多数を占める中に、全角の「ＦＴＰ」だけが混在しています。

**✅ より自然な例（参考例）:**
> WiFiとBluetoothを使う。ダウンロードはFTPで行う。
