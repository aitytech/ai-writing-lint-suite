# カンマの多用をチェックする

**ルールID:** `max-comma` · **重要度:** info · **言語:** 日本語

1つの文の中で半角カンマ「,」が多用されていないかを検出するルールです。日本語の読点「、」とは別に数えられるため、翻訳文や海外の原稿を日本語として整えるときに、カンマを読点代わりに使ってしまっている箇所を見つけるのに役立ちます。

## 例

**❌ 検出される例:**
> あれ,これ,それ,どれ,これ,あれを見る。

**理由:** 1つの文にカンマが5個以上含まれており、既定の上限（4個）を超えています。カンマが多いと文の区切りがどこにあるのか分かりにくくなります。

**✅ より自然な例:**
> あれ,これ,それ,どれを見る。
