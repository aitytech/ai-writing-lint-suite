# 絵文字と太字の機械的な強調

**ルールID:** `no-ai-emphasis-patterns` · **重要度:** error · **言語:** 日本語

「ℹ️ **注意**：〜」のように絵文字と太字を組み合わせたり、「**注意**：」「**重要**：」のような太字の情報プレフィックスを多用したり、見出しの中まで太字にしたりする書き方を検出します。強調の手段を機械的にワンパターンで重ねる書き方は、AIが生成した文章によく見られます。

このルールは公式な出典に基づくものではなく、AI生成文章の強調の使い方についての観察から作られています。

## 例

**❌ 検出される例:**
> ℹ️ **注意**: この機能は重要です

**理由:** 絵文字と太字を組み合わせて注意を引く書き方は、AIが多用する定型パターンです。読み手には機械的に感じられることがあります。

**✅ より自然な例（参考例）:**
> この機能は重要なので、設定前に確認してください。

太字だけを使った情報プレフィックスや、見出し内の余分な太字も同じルールで検出されます。

**❌ 検出される例:**
> **注意**: この設定は重要です

**理由:** 「**注意**：」のような太字プレフィックスを毎回使う書き方も、機械的な印象を与える定型パターンです。

**✅ より自然な例（参考例）:**
> この設定は重要なので、変更前に必ず確認してください。

**❌ 検出される例:**
> # **hoge**

**理由:** 見出しはそれ自体がすでに強調の役割を果たしているため、見出しの中にさらに太字を加えるのは冗長です。

**✅ より自然な例（参考例）:**
> # hoge
