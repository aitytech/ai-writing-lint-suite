# コロンで終える英語構文の直訳

**ルールID:** `no-ai-colon-continuation` · **重要度:** error · **言語:** 日本語

「実行します：」のように述語（動詞や形容詞）で終えた文の直後に、コードブロックや箇条書き、引用、表を続ける書き方を検出します。英語では自然な構文ですが、日本語の地の文にそのまま持ち込むと、読み手によっては英語構文を直訳したような印象を与えます。「使用方法：」のように名詞で終わる場合は自然な日本語として許可されます。

このルールは公式な出典に基づくものではなく、AI生成文章に見られる英語構文の直訳パターンについての観察から作られています。

## 例

**❌ 検出される例:**
> 実行します:
> ```bash
> command
> ```

**理由:** 「実行します」のような述語がコロンで終わり、その直後にコードブロックが続く書き方は、英語の "Run it:" のような構文を直訳した印象を与えます。

**✅ より自然な例（参考例）:**
> 次のように実行します。
> ```bash
> command
> ```

箇条書きが続く場合も同じパターンで検出されます。

**❌ 検出される例:**
> 説明します:
> - 項目1
> - 項目2

**理由:** 述語＋コロンのすぐ後に箇条書きが続く構成も、同じ英語構文の直訳パターンとして検出されます。

**✅ より自然な例（参考例）:**
> 次の項目について説明します。
> - 項目1
> - 項目2
