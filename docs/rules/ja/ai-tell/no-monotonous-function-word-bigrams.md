# 単調な助詞の並び

**ルールID:** `no-monotonous-function-word-bigrams` · **重要度:** info · **言語:** 日本語

段落の中で助詞が2つ連続して現れるパターン（例：「は」の次に「を」）の種類の偏りを測り、「〜は〜を〜します」のような同じ格構造の文ばかりが続く段落を検出します。文の骨格が単調になるのは、AIが生成した文章の統計的な特徴として知られています。

このルールは公式な出典に基づくものではなく、日本語の技術書コーパスを実測して決めたしきい値を使う内部ルールです。この指標は段落が短いほど厳しく出やすい性質があり、実測サンプルも技術書ジャンルに偏っているため、AI文章をどれだけ正しく拾えるかは検証されていません。

## 例

**❌ 検出される例:**
> 本機能は業務を効率化します。本機能は時間を短縮します。本機能は費用を削減します。本機能は品質を向上します。本機能は負担を軽減します。本機能は工数を圧縮します。本機能は精度を改善します。

**理由:** すべての文が「〜は〜を〜します」という同じ助詞の並びで組み立てられており、助詞バイグラム13件のうち「はを」「をは」の2種類しか出てきません。同じ格構造の文を繰り返すのは、AIが書いた文章の統計的な特徴です。

**✅ より自然な例（参考例）:**
> この機能を使うと、業務が効率化されます。時間の短縮にもつながり、費用面でも負担が軽くなります。品質は工数を圧縮しながら改善していけるのが特長です。
