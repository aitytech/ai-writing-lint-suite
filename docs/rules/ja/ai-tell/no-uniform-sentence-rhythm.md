# 単調な文のリズム

**ルールID:** `no-uniform-sentence-rhythm` · **重要度:** info · **言語:** 日本語

段落の中で、連続する文（既定では4文）の長さがほとんど揃っている状態を検出します。長い文と短い文が混ざらず、金太郎飴のように同じ長さの文が続くリズムは、AIが生成した文章の統計的な特徴として知られています。

このルールは公式な出典に基づくものではなく、日本語の技術書コーパスで実測したしきい値を使う内部ルールです。人間が書いた文章の技術書ジャンルでは実測で誤検出率1%程度に収まっていますが、小説や広報文など他ジャンルでの精度は未検証で、AI文章をどれだけ正しく拾えるか（再現率）についても検証されたデータはありません。あくまで参考情報として使うことをおすすめします。

## 例

**❌ 検出される例:**
> 本サービスは業務の効率化を強力に支援します。導入により作業時間を大幅に削減できます。運用コストの最適化にも大きく貢献します。担当者の負担を着実に軽減してくれます。

**理由:** 4つの文がいずれも20〜21文字程度で、長さがほとんど揃っています。長短の変化がない単調なリズムは、AIが書いた文章によく見られる特徴です。

**✅ より自然な例（参考例）:**
> 本サービスは業務の効率化を支援します。実際に使ってみると、設定さえ済ませれば導入までの負担はほとんどありません。作業時間も削減できます。ただし、担当者への説明だけは丁寧に行ったほうがいい。
